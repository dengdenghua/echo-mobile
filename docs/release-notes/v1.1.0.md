## 升级前必读 · Read before upgrading

**这次更新要先卸载旧版。** 1.1.0 换了新的签名密钥（旧版的密钥已遗失），Android 不允许把它覆盖安装到
1.0.0（原「八爪鱼」/ Octopus Mobile）上，直接安装会提示「应用未安装」。

1. 如果在旧版里填过自己的模型 API Key，先记下来。
2. 在系统设置 → 应用里卸载「八爪鱼」。
3. 安装本页的 APK（不确定选哪个就用 `universal`）。
4. 打开 Echo，用原来的邮箱登录，或选「不登录使用」。

卸载会清除这台手机上的对话记录和本地设置，1.0.0 没有导出功能。账号、积分和会员保存在服务器上，登录后都在。

**Uninstall the old version first.** 1.1.0 is signed with a new key (the old one was lost), so Android will not
install it over 1.0.0 (formerly Octopus Mobile); installing on top fails with "App not installed".

1. If you entered your own model API key in the old app, write it down.
2. Uninstall "Octopus Mobile" in system Settings > Apps.
3. Install an APK from this page (`universal` if unsure).
4. Open Echo and sign in with the same email, or choose "Use without an account".

Uninstalling deletes the chats and local settings on the phone; 1.0.0 has no export. Your account, credits and
membership live on the server and come back when you sign in.

## 1.1.0 新内容 · What's new

- **不登录使用 / Use without an account**：登录页可以直接进入本地模式：用自己配置的模型对话、改模型设置、
  连接自己的 Echo（`echo://` 邀请）。积分、社区互动、语音通话、云同步等账号功能显示「登录后可用」，
  随时可以在设置里登录，本机数据不受影响。Chat with your own model, change model settings and pair with your
  own Echo without an account; account features say "Sign in to use this" and you can sign in later from Settings.
- **ECHO 新身份 / Echo identity**：应用改名 Echo，新的图标、配色（Graphite 深色 / Snow 浅色）。
- **Dot 设备与跨设备任务 / Dot devices and cross-device tasks**：一次配对电脑或 NAS，把任务发过去并跟进进度。
- **HUB 与抽屉 / HUB and drawer**：智能体 / 应用 / 技能，自动化；与桌面端侧边栏一致。
- **更稳的更新 / Safer updates**：以后再遇到签名不一致，应用会直接说明要先卸载，而不是让系统安装器报「应用未安装」。

完整变更见 `CHANGELOG.md`。Full list in `CHANGELOG.md`.
