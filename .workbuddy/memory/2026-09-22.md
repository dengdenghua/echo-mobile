### 3. 修掉 48 个 lint 错误(其中多数是真缺陷,不是风格问题)
- **crash 风险**:HardwareDetector 用 R(30) 判 API 31 字段(SOC_MANUFACTURER)、
  JsonRpcDispatcher 用 orTimeout(Java 9+,Android 要 API 31)、
  OctopusBridge 用 createPredefined(API 29+)却按 O(26) 判定
- **功能失效**:Manifest 已开 enableOnBackInvokedCallback 且 targetSdk 36 →
  MiniAppActivity 的 onBackPressed override 是永不执行的死代码(返回手势直接关掉
  mini-app 而不回退 WebView 历史);BaseActivity 里 dispatchKeyEvent 拦 KEYCODE_BACK 重复
- VirtualDisplayService:0x1 or 0x4 换成具名 DisplayManager 常量;
  删掉对 MotionEvent.setDisplayId 的反射(公开 SDK 无此方法,javap 复核 android-36.1,属死路径)
- 26 处 MissingDefaultResource + 14 处 MissingTranslation 补齐
- 提交:6c7a19d
